ClinicPilot always runs its safety rules first. When a Gemini API key is set on the server, the AI layer also writes the patient message and reception summary and can raise urgency, but never lower it below the rules. To turn AI on, put GEMINI_API_KEY=your-key in a .env file next to app.py and restart the server. The key never reaches the browser.

Design

How a request moves through ClinicPilot

Reception at a 7-day clinic fields hundreds of calls and web requests. ClinicPilot sorts them so the sickest patients are seen first, simple admin goes to telehealth, and staff read one consistent summary instead of free text.

  1. Intake

    Patient describes the problem in plain words, plus duration, severity and a red-flag checklist.

  2. Safety screen

    Deterministic rules scan checkboxes and free text for 9 red-flag patterns and risk factors (age, pregnancy, chronic illness).

  3. AI reasoning

    Optional. Gemini reads the form and the rule result, returns strict JSON: urgency, booking type, patient message, staff summary.

  4. Guardrail merge

    The more urgent of the two levels wins. AI can escalate, never downgrade. Bad or missing AI output falls back to rules.

  5. Reception queue

    Request lands in a queue sorted by urgency and wait time, saved on the server and exportable as CSV.

Safety principles

  • Never diagnoses or names a condition; it only routes the request.
  • Any red flag shows "Call 000" and blocks booking.
  • Self-harm language shows 000 and Lifeline 13 11 14.
  • When unsure, it picks the more urgent level.
  • Every result lists its reasons and whether they came from a rule or the AI.

Built with

  • Python 3 with Flask for the web server and API.
  • Rules engine in Python with regex red-flag detection, so the tool works without AI.
  • Google Gemini API (generateContent, JSON response mode, temperature 0.2), called from the server so the key stays private.
  • Batch script that triages a spreadsheet of requests into a colour-coded Excel report.
  • HTML, CSS and JavaScript for this interface; pytest for automated tests.
